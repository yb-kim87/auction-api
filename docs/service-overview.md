# 서비스 개요

경매 물건 추천 + 카카오 알림톡 관리를 결합한 통합 서비스. 두 개의 레포로 구성된다.

- `auction-api`: NestJS 10 + TypeORM(PostgreSQL) 백엔드
- `auction`: Next.js 14(App Router) + Tailwind 프론트엔드

## 1. 전체 구조

```
auction-api/src/
  auctions/        경매 물건 CRUD, 승인 플로우
  crawler/         경매 물건 크롤링
  recommendation/  회원 조건 기반 물건 추천 엔진
  loan-policy/      대출 정책, 규제지역 판정
  ai/              AI 질의응답, 물건 분석, 지식베이스
  ai-platform/     Normalizer → Feature Engine → Tag Engine 파이프라인
  kakao-notify/    카카오 알림톡 발송, 리드/광고 관리, 외부 연동
  users/ auth/     회원, 권한, 인증
  favorites/       관심 물건
  user-actions/    사용자 행동 로그

auction/src/app/
  /            회원용 메인(추천 물건 리스트)
  /search      상세 검색
  /admin       관리자 콘솔
  /account     내 정보/투자정보 수정
  /consultant  컨설턴트용 물건 등록/관리
  /login /pending
```

## 2. 핵심 도메인

### 경매 물건 관리 (`auctions`, `crawler`)
- 크롤러가 물건을 수집해 `PENDING` 상태로 등록하면, 관리자가 승인(`approved`)해야 회원에게 노출된다.
- 엑셀 대량 업로드, 개별/일괄 승인·반려, 네이버 시세·실거래가 보정 로직 포함.

### 추천 시스템 (`recommendation`)
회원정보 → 대출정책 → 조건 필터+랭킹 순으로 추천 리스트를 만든다.

1. **회원정보(Investment Strategy)**: 투자가능금액, 보유주택수, 생애최초 여부, 연소득, 기존대출액
2. **대출정책(Policy Engine)**: `loan-policy` 모듈에서 정책 선택
3. **추천 엔진**: 물건별로 필요 자기자본을 계산해 예산 내 물건만 필터링, 예산 여유가 큰 물건 우선 정렬(동률 시 AI 가격메리트 태그 보조 신호 사용)

### 대출 정책 (`loan-policy`)
회원의 **주택수 · 생애최초 여부**와 물건의 **규제지역 여부**로 6가지 정책 중 하나가 선택된다.

| 규제지역 | 대상 | 감정가비율 | 낙찰가비율 |
|---|---|---|---|
| O | 생애최초 | 40% | (사실상 무제한, 관리자 조정 가능) |
| O | 무주택 | 40% | (사실상 무제한, 관리자 조정 가능) |
| O | 1주택 이상 | - | 대출 불가 |
| X | 생애최초 | 90% | 90% |
| X | 무주택 | 70% | 80% |
| X | 1주택 이상 | 70% | 70% (사업자대출만) |

- 최종 대출한도 = `min(낙찰가×낙찰가비율, 감정가×감정가비율, 연소득×소득배수)` − 기존대출액
- 규제지역 여부는 관리자가 등록한 지역명(시/도·구/군·읍면동)과 물건 주소의 포함 매칭으로 판정
- 관리자 화면(대출 정책 관리)에서 정책별 비율, 소득 대비 대출 배수, 규제지역 목록을 직접 조정 가능

### AI 플랫폼 (`ai-platform`, `ai`)
- **ai-platform**: Normalizer(데이터 정규화) → Feature Engine(특징값 산출) → Tag Engine(예: "가격메리트검토" 태그 부여)의 3단계 파이프라인. 태그는 추천 엔진의 동률 판정에 쓰인다.
- **ai**: "경매코치 AI"가 내부 지식베이스 + 물건 데이터 + 회원 투자정보를 결합해 물건별 분석과 질의응답을 제공. 지식베이스는 관리자가 구조화·승인하는 초안(draft) 관리 흐름을 가진다.

### 카카오 알림톡 (`kakao-notify`)
가장 파일 수가 많은 모듈. 다음 기능을 포함한다.
- 알림톡 발송(즉시/예약), 발송 로그 관리
- 랜딩페이지 방문 추적, 가입 전환 확인
- 리드(잠재고객) 관리 — 그룹핑, 일별 통계, 재발송, 대량발송
- 광고 소재 관리
- 외부 연동: 아임웹(imweb), 인스타그램, 구글시트, 텔레그램 알림

### 회원/권한 (`users`, `auth`)
- 역할: 관리자(admin) / 컨설턴트(consultant) / 컨설팅 수강생 / 수강생 / 일반회원(member)
- 신규 가입자는 승인 대기(`pending`) 상태를 거친다.

### 즐겨찾기 (`favorites`)
회원별 관심 물건 저장/조회.

## 3. 프론트엔드 페이지

| 경로 | 설명 |
|---|---|
| `/` | 회원용 메인 — 추천 물건 리스트, 즐겨찾기, 프로필 요약 |
| `/search` | 지역/가격대/유찰률/물건유형/진행상태 등 상세 검색 |
| `/admin` | 관리자 콘솔 |
| `/account` | 내 정보/투자정보 수정 |
| `/consultant` | 컨설턴트용 물건 업로드/엑셀 등록/수정 |
| `/login` | 로그인 |
| `/pending` | 가입 승인 대기 안내 |

## 4. 관리자 콘솔 탭

- **물건/데이터 관리**: 경매 물건 등록·수정·승인
- **크롤링 작업**: 크롤러 실행/알고리즘/수익성/검색 설정
- **경매지식**: AI 지식베이스, 카페 지식 관리
- **회원권한 관리**: 회원 역할/승인 관리
- **대출정책**: 정책별 비율, 소득배수, 규제지역 목록 관리
- **AI Platform**: Normalizer/Feature Engine/Tag Engine 설정
- **알림톡 관리**: 카카오 알림톡 발송/리드/광고 소재 관리
