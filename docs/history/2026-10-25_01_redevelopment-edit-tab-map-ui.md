날짜: 2026-10-24 ~ 2026-10-25
함께 읽을 문서: [2026-10-24_01 재개발 구역 매물 조사(서버·네이버·국토부)](./2026-10-24_01_redevelopment-research-naver-molit.md) — 조사 백엔드의 상세 규칙은 거기에 있고, 이 문서는 **화면(프론트)과 재개발닷컴 데이터·스타일**, 전체 흐름·운영 방법을 정리한다.

## 0. 한눈에 보기

관리자 페이지 → 물건 작업 → **재개발물건(수정용)** 탭 하나에서 다음을 한다.

1. 재개발닷컴에서 가져온 **서울 재개발 구역도 2천여 개**를 지도에 그린다(사업유형별 색, 추진중은 점선).
2. 경매코치가 이미 가진 **빌라 경매물건** 중 구역 안(경계 오차 포함) 물건을 지도에 가격 라벨로 찍고 목록으로 보여 준다.
3. 경매물건·구역을 눌러 **조사**(네이버 호가 + 국토부 실거래 → 공시가 → 전세가(공시가×126%) → 갭)를 돌리고, 결과를 표와 지도 라벨(호가 초록·실거래 노랑)로 본다.

> 사용자 규칙(반드시 유지)
> - **이 작업은 "재개발물건(수정용)" 탭에만** 한다. 프론트 변경은 **즉시 Vercel 배포**(`vercel deploy --prod --yes`), 서버는 git push(Railway 자동 배포). 프론트(`young/auction`)는 **git 저장소가 아니다**(커밋 불필요). 서버(`young/auction-api`)는 커밋·푸시.
> - 네이버는 **samsam 프로젝트 방식**(서버에서, curl_cffi 브릿지, 직렬 큐+랜덤 간격)을 그대로 따른다.
> - **재개발닷컴(jaegebal.com)에는 자주 접속하지 않는다.** 한 번 받아 저장해 둔 것을 쓴다(아래 §2). 봇 확인 화면이 뜨면 **우회하지 않고** 사용자가 직접 브라우저에서 풀어 주게 한다.
> - 용도는 **빌라**(다세대·연립·도시형생활주택, 경매코치 propType "빌라").
> - 로컬에서 작업해도 **온라인 DB·API**를 쓴다(`API_ORIGIN`을 운영으로).

## 4. 지도 가격 라벨 (경매 / 호가 / 실거래)

- 라벨 모양: **위쪽 흰 칸**(종류: 경매·호가·실거래) + **아래쪽 종류색 칸**(흰 글씨 금액) + 아래 꼬리. 색: **경매 검정(#1f2937)**, **호가 초록(#16a34a)**, **실거래 노랑(#eab308)**.
- 경매: 금액 = **현재 최저가**(없으면 매각가→감정가), 라벨 **오른쪽 옆** 주황 테두리 뱃지 = **최저가/감정가 %**(예 `80%`). ※ 서버에 유찰 횟수 필드가 없어 "유찰률"을 이 비율로 대신함 — 유찰 횟수를 따로 표시하려면 크롤러 필드 추가 필요.
- 표시 확대 단계(재개발닷컴 줌 임계값 `점 16 / 가격 17` ≈ 카카오 레벨 4/3에 맞춤): 호가·실거래는 레벨 4에서 **점**, 레벨 ≤3에서 라벨. 경매는 핵심이라 한 단계 멀리서도(레벨 ≤6 점, ≤4 라벨).
- 같은 좌표(한 건물)·같은 종류는 한 라벨로 묶고 `외 N` 표기. 그래도 겹치면 우선순위(선택 경매 > 경매 > 호가 > 실거래)로 하나만 남기고 `+N`. 종류별 화면 안 최대 250개.
- **라벨 클릭**: 단독 경매 → 경매 상세 팝업. 그 외(호가·실거래, 묶임·겹침 포함) → **목록 팝업**(맨 위 4칸 = 공시가 / 전세가(126%) / 호가(실거래가) / 갭, 그 아래 매물명·층·중개사·확인일 등, 외부 링크).
- 지도 위 **실거래 / 매물 / 경공매 / 근처 / 구경계** 버튼으로 켜고 끄기(구경계는 서울 구 경계선, 동 경계는 지도 왼쪽 아래 체크박스).
- **구역 근처(경계 밖) 경매물건**: **구역 안 = 실제 다각형 안**(검정)으로만 본다(오차범위로 안쪽 취급하지 않음 — 2026-10-25 수정: 다각형 밖 물건이 오차범위 안이라 검정으로 나와 구분이 안 됐음). 다각형 밖이면 경계에서 **100m 이내**면 "구역일 가능성"으로 함께 표시한다. 라벨은 **진한 회색 + 점선 테두리 + "경매·경계밖"**, 목록·구역 팝업에는 "경계밖" 칩. 지도 위 **"근처" 버튼**으로 숨길 수 있다(숨기면 지도·목록·구역 팝업에서 모두 빠짐). 그보다 먼 물건은 저장·표시 대상이 아니며, "전체 보기"를 켜면 구역 밖 물건이 옅은 회색 "경매·구역밖"으로 나온다.
- **경매물건 지도 자동 반영**: 새 경매물건은 이 탭을 열면(구역 로드 후, 12시간 이내 재실행 방지) 브라우저가 구별로 좌표 없는 빌라를 주소 → 좌표로 바꿔 구역 근처만 저장하고 지도를 갱신한다. **서버가 자동으로 하는 것은 아니다**(탭을 열어야 처리됨). 서버 정기 배치로 옮기는 것은 후보 작업.
- **구·동 필터는 지도를 그 지역으로 옮기기만** 한다. 지도 위 경매·호가·실거래 라벨은 구와 무관하게 전부 유지(지도를 움직이면 다른 지역도 보임). 목록은 구·동 필터를 따른다.
- 호가·실거래 라벨은 **조사를 돌린 구역에만** 존재한다(저장된 데이터). 조사 패널이 끝날 때마다 `["redev-map-points"]` 쿼리를 무효화해 지도가 갱신된다.

## 6. 조사 표 레이아웃(2026-10-25 정리)

열: 분류 · 주소 · 거래일·확인일 · 층·호 · 전용(㎡) · 평 · 대지지분(㎡·평) · 연식 · 방 · 공시가 · 전세가 · **호가/실매도** · **구역갭** · 현전세 · 중개사·연락처 (15열).
- 호가 줄: 호가, 갭 = 호가 − 전세가. 실거래 줄: 실매도(거래가), 갭 = 실거래 − 전세가. 갭 색: +빨강 / −파랑.
- **줄 배경 + 왼쪽 띠**로 종류 구분(호가 옅은 초록·실거래 옅은 노랑·경매물건 회색), 분류 칩도 같은 색.
- 정렬 고정: 경매물건 → 호가(낮은 가격순) → 실거래(최근순). 같은 호 추정 묶음은 호가 칸에 `×N` 칩, 주소 칸에 "같은 호 추정 ×N".
- 전세가율 126%는 표 위 입력값(브라우저 저장)이고, **지도 팝업의 전세가는 126% 고정**.

## 6-1. 경매물건 목록의 구역 필터 (2026-10-25)

지도 아래 경매물건 목록 툴바(경계 오차범위·구역 밖 물건도 보기 옆)에 **사업종류·진행단계 드롭다운**과 **"연번부여만" 빠른 버튼**이 있다. 물건이 속한 구역(여러 개면 하나라도) 기준으로 거르며, 지도 필터·좌측 구역 목록 필터와는 **별개 상태**(`aucTypes`/`aucStages`). "구역 필터 해제"로 한 번에 풀린다.

## 6-2. 목록 주소 클릭 → 지도 이동 (2026-10-25)

경매물건 목록에서 **주소(파란 글씨)를 누르면** 지도가 그 물건 좌표로 이동·확대(카카오 레벨 2)하고 해당 라벨을 강조(검정 외곽선)하며, 목록이 지도 아래에 있으므로 지도가 보이게 화면을 올린다(행 펼침은 하지 않음). 구현: 목록 `onFocusAuction` → 탭 `focusAuction`(`nonce`로 같은 물건도 다시 이동) → `RedevelopmentEditMapView.focusAuction`. 지도에는 별도로 경매 범위(전체/진행/낙찰) 버튼이 추가돼 있다(`auctionScope`).

- 유찰 횟수 대신 최저가율(%)을 표시 중(위 §4).
- 좌표 자동 채우기는 금천·영등포·은평만. 다른 구 경매물건은 좌표가 없어 지도에 안 나온다(`TARGET_GU` 확대 필요).
- 호가·실거래 라벨은 조사한 구역만. 구역 일괄 조사(예: 구 단위 큐)는 없음 — 네이버/국토부 한도 때문에 일부러 한 번에 한 구역.
- 도시형생활주택은 네이버에서 따로 분류되는지 미확인(국토부는 다세대에 묶여 옴).
- 호가 대지지분은 비례 추정(등기부 아님). 공시가는 호수를 모르면 층·면적 추정.
- 지도 팝업 전세가율 126% 고정, 팝업 항목은 조사 표와 다름(요약).
- 재개발닷컴이 "겹침"을 별도 로직으로 처리하는 코드는 찾지 못했다(줌 단계별 점/라벨 전환 + 같은 위치 묶음이 전부). `+N` 겹침 숨김은 우리가 추가한 방식.
- 구역 색 규칙은 JS에서 읽은 값과 일치하지만, 재개발닷컴이 이후 바꾸면 달라질 수 있다(저장본 기준 2026-10-25).

## 10. 이 작업의 사용자 요청 흐름(요약)

구역도 import(영등포 샘플→서울 전체, Playwright) → 운영 DB 연결 → 옛 구역 숨김·경매 점 표시·좌표 자동 채우기 → 재개발닷컴 레이아웃(좌 정보/우 큰 지도)·성능 개선 → 경매 목록(필터·정렬·메모·관심) → 조사 기능(samsam 방식 네이버 + 국토부 + 공시가) → 빌라 한정·DSD/YR 포함 → 정확 지번(fin.land)·층 추정 보강 → 호가 묶기·대지지분·중개사 열 → 가격 라벨·사업유형 색·재개발닷컴 스타일 → 라벨 디자인·유찰% 뱃지 → 경매/구역 팝업·필터·구역 조사 버튼 → 조사 표 열 간소화·줄 배경색.
