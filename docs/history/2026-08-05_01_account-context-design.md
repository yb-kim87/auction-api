# 회원정보 진입 맥락별 디자인 분리

## 배경

강의실과 경매 물건 탐색 영역은 서로 다른 경험으로 인식되도록, 회원정보 화면도
진입한 서비스 영역의 디자인 언어를 따라야 한다.

## 요청 요약

- 강의실에서 `내 정보`를 열면 현재의 보라색 강의실 회원정보 디자인을 유지한다.
- 경매/추천 물건 화면에서 회원정보를 열면 이전의 경매 서비스용 디자인으로 표시한다.
- 계정 정보와 비밀번호 변경 API 및 저장 동작은 동일하게 유지한다.

## 변경 내용

- 프론트엔드 `/account`에서 `context=lecture` 쿼리 여부로 뷰를 선택하도록 구현했다.
- `/courses`, `/courses/[courseId]`의 `내 정보` 링크는 `/account?context=lecture`로 연결했다.
- 기본 `/account`는 기존 경매 서비스의 헤더와 카드/폼 밀도를 사용하는 회원정보 뷰를
  표시하도록 복원했다.
- 두 뷰는 동일한 프로필 조회, 이름 변경, 비밀번호 변경, 로그아웃 로직을 공유한다.

## 결과

- 강의실과 경매 서비스의 시각적 경계는 분명해졌고, 회원정보 관리 기능은 중복 구현 없이
  동일하게 동작한다.
- `useSearchParams`를 사용하는 회원정보 분기에는 Suspense 경계를 적용해 Next.js 정적
  렌더링 오류를 방지했다.
- 프론트엔드 TypeScript 검사(`npx tsc --noEmit`)와 프로덕션 빌드(`npm run build`)를
  통과했다.

## 후속 개선: 강의실과 물건 서비스 이동 경로 분리

- 강의실 대시보드와 강의 시청 화면의 `코치픽` 로고는 항상 `/courses`로 이동하도록
  변경했다. 학습 중 로고를 눌러도 물건 추천 화면으로 이탈하지 않는다.
- 강의실 대시보드, 강의 시청 화면, 강의실 문맥의 회원정보 헤더에 `물건 추천` 버튼을
  추가했다. 사용자가 이 버튼을 눌렀을 때만 경매 물건 서비스(`/`)로 이동한다.
- TypeScript 검사(`npx tsc --noEmit`)를 통과했다.
