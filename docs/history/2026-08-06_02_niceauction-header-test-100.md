# 나이스옥션 브라우저 헤더 방식 100건 테스트

## 테스트 조건

- 실제 유효한 나이스옥션 `objId` 100건
- `GET /api/v1/obj/{objId}?privacy=true`
- Chrome User-Agent, Accept, Accept-Language, 동일 출처 Referer 및 Sec-Fetch 헤더 적용
- 응답 본문은 저장하지 않고 HTTP 상태와 API 코드만 집계

## 결과

| 항목 | 결과 |
|---|---:|
| 전체 요청 | 100건 |
| 상세 객체 정상 반환 | 100건 |
| 실패 | 0건 |
| API 코드 | `code=0` 100건 |
| 12건 이후 차단 | 없음 |

## 결론

브라우저 요청 헤더를 적용하면 현재 확보된 표본에서는 100건 연속 조회가
성공했다. 기존 12건 제한은 API 절대 한도라기보다 요청 헤더·Referer·브라우저
식별 정보가 부족한 호출에서 발생했을 가능성이 높다.

다만 운영 전환 전에는 장시간·지역 분산·재시도 상황의 추가 테스트와
나이스옥션 이용약관 및 제휴 조건 검토가 필요하다. 현재는 자동 운영 크롤러에
연결하지 않고 검증 결과만 기록한다.
