# 재개발 구역 편집 실행취소 추가 (2026-08-06)

## 변경 내용

- 이미지 기반 구역 편집기에 최대 30단계의 편집 이력 스택을 추가했다.
- `Ctrl+Z`와 macOS `Cmd+Z`로 개별 점 드래그, 구역 전체 이동, 점 삭제, 마지막 점 취소, 경계 지우기, 새 점 추가를 한 단계 이전 상태로 되돌린다.
- 드래그는 시작 시점에 한 번만 이력을 기록해 이동 중 수십 개의 이력이 쌓이지 않도록 했다.
- 입력창을 편집 중일 때는 브라우저/입력 컨트롤의 기본 실행취소를 유지한다.

## 검증

`auction` 프론트엔드에서 `npm.cmd run build`를 실행해 컴파일과 타입 검사를 통과했다.
