# 물건 상세 권리분석 UX 및 탭 상태 유지

날짜: 2026-07-29

## 배경

물건 상세의 권리분석 결과가 내부 분석 자료의 존재 여부를 설명하는 방식에 치우쳐 있어, 사용자가 실제로 알고 싶은 입찰 가능 여부와 인수 예상금액을 빠르게 파악하기 어려웠다. 또한 기본정보, AI 권리분석, 수익계산기 탭을 이동할 때 각 탭의 컴포넌트가 다시 생성되어 분석 결과와 계산기 입력값이 초기화되는 문제가 있었다.

## 사용자 중심 권리분석 표시

- 권리분석의 최상단 결론과 상세 상단의 권리분석 상태 카드를 같은 판정과 색상으로 연결했다.
- 상태 색상은 다음 의미로 사용한다.
  - 초록색: 현재 확보된 자료 기준으로 인수 위험이 확인되지 않아 입찰 검토가 가능한 상태
  - 노란색: 자료 또는 권리관계를 추가 확인한 뒤 입찰해야 하는 상태
  - 빨간색: 인수 가능 권리 등 주요 위험이 확인된 상태
- `낙찰 후 부담 가능 금액`은 사용자에게 더 직접적인 `인수예상금액`으로 변경했다.
- 대항력 있는 임차인이 없고 예외 권리가 감지되지 않은 경우 인수예상금액을 `0원`으로 표시한다.
- 임차인 자료의 단순 존재 여부 대신 `임차인 없음`, `대항력 없음`, `확인 필요`처럼 판단 결과를 표시한다.
- 등기자료 유무 카드는 모든 물건에서 의미가 작아 말소기준권리와 기준일을 보여주는 카드로 교체했다.
- 미납 관리비는 권리위험 결론을 자동으로 빨간색으로 만드는 요소에서 제외하고 참고 금액으로 분리했다.
- 사용자가 판단 결과에 집중할 수 있도록 내부 RAG 근거 목록, 미확인 자료 목록 등 운영용 설명은 일반 사용자 화면에서 숨겼다.
- 최종 안내에는 법원 제공자료 기준의 결과임을 명시하고 최신 등기부와 매각물건명세서를 확인하도록 안내한다.

## 확정 규칙과 AI 호출

- 날짜와 자료만으로 확정할 수 있는 소유자 점유, 조사된 임차내역 없음, 말소기준일과 전입일 비교 등은 서버 확정 규칙으로 처리한다.
- 전입일이 말소기준일과 같은 경우에도 전입 효력은 다음 날 0시부터 발생하는 현재 규칙을 적용해 대항력 없음으로 판정한다.
- 서버 확정 규칙으로 결론을 낼 수 있는 사건은 RAG 검색과 AI 호출을 생략하며 사용자 AI 이용 횟수도 차감하지 않는다.
- 선순위 대항력 임차인, 임차권등기, HUG 등 보증기관 채권승계·포기, 유치권·법정지상권 등 예외 또는 복합 사건만 RAG와 AI 설명을 사용한다.
- 관리자는 권리분석 화면에서 해당 결과가 AI 호출을 사용했는지, 사용 횟수 차감 대상인지 확인할 수 있다.
- `새 지식 반영해 다시 분석` 기능은 관리자에게만 노출한다.

## 임차인 정보 표시 보완

- 전입일이 말소기준일보다 늦거나 같은 임차인은 대항력 값을 `X`로 표시한다.
- 보증금 원문이 `이상`처럼 금액을 알 수 없는 표현이면 금액이 있는 것처럼 보이지 않도록 `미상`으로 정규화한다.
- 임차인·점유 현황 표의 열 너비와 줄바꿈을 정리해 긴 전입·확정·배당 정보와 기타 설명이 겹치지 않게 했다.
- 승계된 임차인의 중복 가능성을 알리는 내부성 문구는 사용자 화면에서 제거했다.

## 상세 탭 상태 유지

- 기존에는 선택한 탭만 조건부 렌더링하여 탭을 이동할 때 AI 권리분석과 수익계산기 컴포넌트가 언마운트되었다.
- 세 탭을 상세 모달 안에 계속 마운트하고 선택하지 않은 탭만 숨기도록 변경했다.
- 상세창이 열려 있는 동안 다음 상태가 유지된다.
  - 이미 조회하거나 실행한 권리분석 결과
  - 수익계산기에 사용자가 입력한 입찰가, 매도가, 비용과 기타 계산 조건
- 다른 물건을 열면 물건 ID를 기준으로 권리분석과 계산기 상태가 새로 초기화된다.
- 상세창을 닫았다가 다시 열면 새 상세 세션으로 처리한다.

## 검증

- 프론트엔드 프로덕션 빌드 통과.
- 기본정보 → AI 권리분석 → 기본정보 → AI 권리분석 이동 시 기존 결과 유지.
- 수익계산기 → 기본정보 → 수익계산기 이동 시 입력 상태 유지.
- 물건 ID 변경 시 이전 물건의 상태가 다음 물건에 이어지지 않도록 컴포넌트 키 적용.

## 追記 (2026-08-04) — 물건 상세 정보 구조와 핵심 가격 요약 개편

물건 상세 모달에서 표가 화면을 가득 채우고 핵심 투자 판단 정보가 여러
영역에 중복되던 문제를 정리했다.

- 상단에 투자 판단 요약(최소 필요자금, 가격 여유, 권리분석 상태,
  입찰 일정)을 배치하고 입찰기일까지 남은 기간을 `D-n`/오늘/종료/기일
  변경 상태와 실제 날짜로 함께 표시한다.
- 소재지 영역에 `주소 복사` 기능을 추가했으며 복사 결과를 사용자에게
  피드백한다. 외부 경매지에서 가져온 흔적처럼 보일 수 있는 조회수는
  화면에서 제거했다.
- `핵심 가격 요약`은 우측 투자금 카드와 중복되던 감정가·최저가·최소
  필요자금 나열을 줄이고 주변 매물 호가를 중심 정보로 재구성했다.
  현재 최저가와 감정가는 비교 카드로 배치하고 가격 차이를 명시한다.
- 존재하지 않는 `예상 낙찰가`는 분석 전/후 모두 표시하지 않는다.
  낙찰 완료 물건에만 실제 낙찰가를 보여준다.
- 인근 실거래 신고 건수는 최근 연도별 막대그래프로 바꿔 표본의 양과
  시계열 분포를 한눈에 볼 수 있게 했다. 동일 조건 매매 수와 완전히 같은
  지표가 아니라는 안내를 유지한다.
- 네이버 단지 정보가 없는 빌라·다세대 등은 호가를 억지로 생성하지 않고
  가격 여유를 `확인 필요`로 표시하며, 확보된 실거래 표본과 법원 가격
  정보만 보여준다.
- 등기 권리내역은 말소기준권리, 등기 채권액 합계, 인수 가능성 요약을
  먼저 제시한다. 경매 청구금액은 등기 채권과 중복될 수 있으므로 합계에
  더하지 않고 별도 값으로 표시한다. 말소 여부는 접수일과 권리 종류에
  따른 화면 보조 판정이며 최종 판단은 매각물건명세서와 등기사항증명서
  확인이 필요하다는 안내를 추가했다.

## 追記 (2026-08-05) — 상세 모달의 바깥 스크롤 제거

상세 정보가 길어질 때 모달 자체가 뷰포트보다 길어져, 모달 뒤의 오버레이
영역에 불필요한 세로 스크롤이 생기던 문제를 수정했다.

- 데스크톱 모달을 `100dvh - 3rem` 높이로 고정하고 화면 중앙에 배치.
- 헤더는 고정한 채 본문 영역만 남은 높이를 사용해 내부 스크롤한다.
- 모바일은 기존 전체 화면 스크롤 방식을 유지한다.
- 핵심 가격 요약과 첫 상세 아코디언 사이에는 12px 간격을 둬 요약 영역과
  상세 정보 묶음의 경계를 명확히 했다.

### 후속 보완
우측 투자금 사이드바에도 별도 `overflow-y-auto`가 남아 있어 화면 높이가
작을 때 본문 스크롤과 사이드바 스크롤이 동시에 표시될 수 있었다. 사이드바의
자체 최대 높이·세로 스크롤을 제거해 모달 본문 스크롤 하나로 통일했다.
