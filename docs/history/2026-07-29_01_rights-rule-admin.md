# 관리자 권리분석 코드 규칙

## 목적

법령 개정 시 배포 없이 권리분석의 핵심 판정 기준을 관리자가 변경할 수
있도록 코드 규칙과 운영 설정을 분리한다.

## 적용 내용

- `rights_analysis_rules` 테이블과 관리자 전용 조회·수정 API 추가.
- 관리자 `AI운영`의 `AI지식` 앞에 `권리분석` 탭 추가.
- 각 규칙에 현재 적용값, 설명, 법령·판정 근거, 수정자·수정 시각 표시.
- 잘못된 자유 입력을 막기 위해 코드가 지원하는 안전한 선택지만 제공.
- 대항력 발생 시점:
  - `다음 날 0시부터`: 동일 날짜 전입은 후순위.
  - `요건 충족 즉시`: 동일 날짜에 시각 정보가 없으면 선후순위 미확인.
- 조사된 임차내역 없음:
  - 임차인 권리 없음 자동 판정.
  - 추가 확인 필요 상태 유지.
- 청구금액과 인수금액 분리 등 안전 규칙은 조회만 가능하고 수정 불가.

## 적용 범위

변경된 규칙은 이후 새로 생성하거나 관리자가 강제 재분석한 결과부터
적용한다. 기존 공용 분석 결과는 자동 갱신하지 않는다.
