# 관리자 작업공간 확장 및 재개발 구역 편집 개선 (2026-08-06)

## 배경

관리자 물건·데이터 관리 화면은 업로드 영역과 데이터 표를 함께 사용하지만 최대 폭이 960px로 제한되어 있었다. 또한 재개발 구역 수정 시 지도 배율과 용도지역도 표시를 매번 수동으로 조절해야 했고, 불필요한 경계 점을 삭제할 방법이 없었다.

## 변경 내용

- 관리자 헤더와 본문 최대 폭을 `960px`에서 `1600px`으로 확대했다. 모바일에서는 작은 좌우 여백으로 자연스럽게 축소된다.
- 이미지 기반 구역 수정 도구는 진입 시 카카오맵 `USE_DISTRICT` 용도지역도를 기본 표시한다.
- 기존 경계가 있으면 해당 폴리곤 범위에 맞춰 지도를 자동으로 맞추고, 신규 구역은 초기 중심점 기준 기본 배율을 적용한다. 자동 추출 경계는 기존처럼 면적 기준 배율로 다시 맞춘다.
- 경계 점 클릭 시 선택 상태를 표시하고, 선택한 점은 `Delete` 키로 삭제할 수 있다.
- 점 위 우클릭은 삭제 확인을 제공한다. 점이 아닌 지도 영역의 우클릭은 차단하지 않는다.
- 폴리곤의 최소 요건을 보존하기 위해 점이 3개 이하일 때는 삭제하지 않는다.

## 영향 범위와 검증

- 지도 전체 이동, 폴리곤 전체 드래그, 개별 점 드래그의 기존 DOM 이벤트 처리에는 변경을 가하지 않았다. 삭제는 점 히트 영역에서만 동작한다.
- 프론트엔드에서 `npm.cmd run build`를 실행해 컴파일·타입 검사를 통과했다.
