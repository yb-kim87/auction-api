# 관리자 화면 "크롤링" 표현을 "물건 작업"으로 순화

날짜: 2026-07-26
관련 레포: auction

## 요청 원문 (요약)
"우리 관리자 페이지에서 크롤링 이라는 표현들을 쓰고 있는데 이걸 이제
바꾸자. 물건 업데이트 이런식으로 확인해보고 크롤링이라는 표현을 다
수정해줘" → (라벨 후보 조정) "물건 업데이트 말고 물건 작업으로 가자"
→ "너무 기니까"(작업창 헤더도 축약).

관리자 화면에 노출되는 "크롤링"이라는 표현이 일반 사용자/운영자
입장에서 기술적이고 낯설다는 이유로, 사용자 대면 UI 문구만 순화하기로
함(내부 코드/주석/변수명은 유지).

## 조사 방법
`grep -r "크롤링" src`로 6개 파일을 찾은 뒤, 각 매치가 실제 화면에
렌더링되는 UI 텍스트인지, 아니면 코드 주석/변수명처럼 화면에 안
보이는 것인지 하나씩 구분했다. 또한 "크롤링"이라는 단어가 두 가지
완전히 다른 의미로 쓰이고 있음을 확인:
- 우리가 자체적으로 물건 데이터를 수집하는 작업(순화 대상)
- 보안 로그 탭에서 "외부의 악성 크롤링을 탐지"한다는 의미(순화 대상
  아님 — 오히려 "크롤링"이 정확한 용어)

## 변경 내용 (auction 레포, UI 텍스트만)
- `src/app/admin/page.tsx`:
  - 상단 탭 라벨 "크롤링 작업" → **"물건 작업"**
  - "DB 데이터 관리" 섹션 안내 문구 "크롤 조회 후" → "물건 조회 후"
- `src/app/admin/CrawlerWorkPanel.tsx`:
  - 작업창 헤더 "크롤링 작업창" → **"물건 작업창"**
  - "크롤러 워커에 원격 연결됩니다" → "수집 워커에 원격 연결됩니다"
  - "크롤 워커가 돌아가는 PC" → "수집 워커가 돌아가는 PC"
  - "그 PC에서는 크롤을 실행할 수 없습니다" → "그 PC에서는 수집을
    실행할 수 없습니다"
  - "원격 크롤 — Chrome은..." → "원격 수집 — Chrome은..."

## 변경하지 않은 것 (의도적)
- `src/app/admin/SecurityLogTab.tsx`의 "크롤링·자동화 스크립트로
  의심되는 패턴" — 외부 악성 크롤링 탐지 기능 설명이라 그대로 유지.
- `CrawlerWorkPanel.tsx`의 `title="Python 크롤러 코드 변경 후 반드시
  실행"` — 버튼 위 툴팁으로 개발자/운영자 대상 정확한 기술 설명이라
  유지.
- `ProfitCalculatorPanel.tsx`, `app/api/vat/calc/route.ts`,
  `types/auction.ts`의 "크롤링" — 전부 코드 주석이라 화면에 노출되지
  않음, 변경 불필요.
- 컴포넌트/파일명(`CrawlerWorkPanel.tsx`, `CrawlerDailyJobTab.tsx` 등),
  타입명(`CrawlerConfig` 등), API 경로(`/crawler/*`), DB 테이블/컬럼명
  (`crawler_log`, `crawler_config` 등)은 이번 작업 범위 밖 — 코드
  전반에 광범위하게 쓰이는 내부 식별자라 UI 텍스트 변경과 분리해서
  판단해야 함(리네이밍 시 별도 요청 필요).
