## 앞으로의 작업 방식

1. 새 요청이 들어오면 먼저 이 폴더의 기존 문서들을 훑어 가장 유사한 카테고리(주제)의
   문서가 있는지 확인한다.
   - 유사 문서가 있으면: 그 문서의 배경/기존 결정 사항을 참조해 일관된 방식으로 작업하고,
     작업 후 변경 내용과 결과를 **같은 문서에 追記**한다(새 파일을 만들지 않음).
   - 유사 문서가 없으면: 새로운 주제로 판단해 새 문서를 만든다.
2. 작업을 시작하기 전, 해당 작업의 목적/범위를 담은 프롬프트를 먼저
   `docs/history/YYYY-MM-DD_NN_주제.md`(신규) 또는 기존 문서에 작성한 뒤 그 내용을 기반으로 실행한다.
3. 작업이 끝나면 같은 문서에 변경 내용과 결과를 追記한다.
4. **기존 문서 내용이 이번 작업으로 더 이상 사실과 맞지 않게 되면(표, 정책 값, 구조 설명 등)
   追記만 하지 말고 해당 서술 자체를 갱신한다.** 예: 정책 구조를 다시 바꾸면 이전 문서의
   정책표도 최신 상태로 고친다. 과거 결정 이력 자체는 지우지 않되(무엇을 왜 바꿨는지는
   남기고), "현재 상태"를 설명하는 부분은 항상 최신값과 일치시킨다.
