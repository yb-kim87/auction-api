# 작업 히스토리

기능 단위 작업 내역을 날짜별로 정리한다. 파일명 규칙: `YYYY-MM-DD_NN_주제.md`.
각 문서는 배경, 실제 실행한 프롬프트(요약), 변경 내용, 결과를 포함한다.

## 앞으로의 작업 방식

새 작업을 시작하기 전, 해당 작업의 목적/범위를 담은 프롬프트를 먼저
`docs/history/YYYY-MM-DD_NN_주제.md` 형태의 파일로 작성한 뒤 그 내용을 기반으로 실행한다.
작업이 끝나면 같은 문서에 변경 내용과 결과를 追記한다.
