# 재개발 구역 편집 저장 유지 및 점 드래그 수정 (2026-08-06)

## 변경 내용

- 저장된 기존 폴리곤을 편집할 때 개별 점 드래그가 이미지 좌표를 참조해 멈추던 문제를 수정했다. 저장 경계점과 현재 폴리곤 이동량을 기준 좌표로 사용한다.
- `이 경계로 확정`은 구역 수정 저장 후 편집 창을 닫지 않는다.
- 버튼 왼쪽에 저장 성공 또는 실패 메시지를 표시하고, 저장 중에는 중복 확정을 막는다.
- 신규 구역 생성의 다음 입력 단계 전환은 기존 흐름을 유지한다.

## 검증

`auction` 프론트엔드에서 `npm.cmd run build`를 실행해 컴파일과 타입 검사를 통과했다.
