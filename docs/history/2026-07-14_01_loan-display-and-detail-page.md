# 대출 표시 버그 수정 및 상세페이지 대출 정보 고도화

날짜: 2026-07-14
관련 레포: auction, auction-api

## 배경

추천 물건 카드에 예상 대출금액을 표시하던 중, "최소투자금과 예상대출금이 똑같이 나온다"는
제보를 계기로 조사한 결과 두 가지 문제가 확인됨.

1. 화면에 정책의 raw `loanRatio`(낙찰가비율)를 그대로 "대출 OO%"로 표시하고 있었는데,
   실제로는 감정가비율이 더 낮게 걸려 다른 비율이 적용되고 있었음(표시 버그, 계산 자체는 정상)
2. 소득 0원이 "정보 없음"과 동일하게 취급되어 소득 기준이 전혀 적용되지 않던 버그

## 실행 프롬프트 (요약, 시간순)

```
최소 투자금 나오는 곳에 예상 대출금액도 표시해주면 좋을꺼같은데
(스크린샷) 이렇게 나오는게 맞아?? 최소투자금이랑 대출이 나오는 값이 똑같은데 9920만원으로
관리자 콘솔에서 /api/recommendations?limit=5 API 응답을 직접 확인해줘
서울특별시(또는 '서울') 전체를 규제지역으로 등록해둔 거 같아요
서울 전체가 실제 규제지역이 맞음(그대로 유지)
아그러면 앞에다가 규제지역 생애최초포함 대출 40% 이런식으로 써줘야하는데 80%라고 써져있을까
둘 다: 표시를 min(감정가,낙찰가)로 고치고, 규제지역은 낙찰가 입력란도 숨김
아미 의미없는 값은 아닌데 낙찰 값 80%와 규제지역을 적용한 감정가 40% 이 부분 중 낮은 값이 적용되는거니까
그리고 규제지역도 표시해줘 / 비규제지역만 표시하지말고
현재 대출관련 내용 요약본을 MD파일로 만들어줘 / 계산식까지해서 / 반영해줘
그리고 상세 페이지 부분 여기도 카드 내용이 적용이 되어야할꺼같고 상세페이지에서 대출내용을
좀 구체적으로 써주자 최저입찰가 감정가 써진 위치에 감정가40% 얼마 낙찰가80% 얼마 최종대출금 얼마
최소투자금 얼마 이런식으로 나오게
여기에 대출 금액 표시할때 규제/무주택(생애최초) 감정 40% 얼마 낙찰 80% 중 낮은 금액 최종 대출 1.4억
이렇게 표현해 주는게 어때
굳이 감정가 40%가 얼마고 낙찰가 80%가 얼마고는 안나와도 될꺼같고 최종 계산식에 대한 대출값만
보여주면 될꺼같아 너무 길어지니까
좋아 근데 이부분을 좀더 보기 좋게 어떻게 안될까?? (계산 그룹화 + 시각적 강조 레이아웃 채택)
그리고 여기 빨간박스친 80% 유찰된 금액은 최저입찰가 우측으로 가면 될꺼같아 하단에
여기서 대출 금액 표시할때 소득적용대출 3.5억, 기존대출 차감(0원/5천 등)도 넣어주자
```

## 변경 내용

### 백엔드 (auction-api)
- `src/recommendation/investment-math.util.ts`: `parseIncomeToWon` 신규 추가(소득 "0"을
  유효값으로 인정). `needsCreditScoreWarning` 등 서버사이드 필터 로직 포함.
- `src/recommendation/recommendation-engine.service.ts`: `loanInfoByItemId`에
  `regulatedArea`, `incomeLoanLimit`(소득×배수 한도), `existingLoanWon`(기존대출액) 필드 추가.

### 프론트엔드 (auction)
- `src/app/page.tsx`
  - 카드/리스트뷰에 규제지역·비규제지역 배지 추가
  - "대출 OO%" 대신 최종 대출금액(`finalLoanAmount`)만 간결하게 표시, "예상대출"로 문구 변경
  - `shortLoanPolicyLabel`/`housingLoanLabel`로 정책 라벨을 "무주택"/"무주택생애최초"로 표시
- `src/components/AuctionDetailModal.tsx`
  - "최소 투자금" 카드에 "대출 기준액 비교" 박스 추가 — 감정가/낙찰가/소득적용대출 중
    최저값에 "최저" 강조 표시
  - 기존대출 차감 내역, 최종대출금/최소투자금 하이라이트 박스 추가
  - 유찰률 배지를 최저입찰가 옆으로 이동
- `src/lib/loan-policy-label.ts` 신규: 정책 라벨 가공 로직을 카드/상세페이지가 공용으로 사용

## 결과
- 소득 5000만원, 기존대출 0원 등 회원 투자정보가 실제로 대출 계산에 반영됨을 확인
- 카드와 상세페이지가 서로 다른 정보 밀도(카드=요약, 상세=계산 근거 전체)로 일관되게 개편됨
