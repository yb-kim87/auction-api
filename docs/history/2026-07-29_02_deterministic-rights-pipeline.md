# 권리분석 확정 판정 우선 파이프라인

날짜: 2026-07-29

## 목표

권리분석의 기본적인 날짜·임차관계 판단을 LLM과 RAG에 맡기지 않고 서버가
동일하게 판정한다. RAG는 HUG 등 복잡한 예외 검토에 사용하고 AI는 사용자용
설명을 작성한다. AI가 확정 판정과 반대되는 응답을 반환하면 서버가 최종 결과를
교정한다.

## 처리 순서

1. 등기·임차·특이사항 원문에서 구조화된 사실을 추출한다.
2. 서버 확정 규칙으로 기본 권리관계를 판정한다.
3. 유치권·법정지상권·보증기관 채권 승계 등 복잡한 신호만 RAG 검토 대상으로
   남긴다.
4. AI가 설명을 작성한다.
5. 서버가 AI의 구조화 결과를 확정 판정과 다시 대조하고 불일치 값을 덮어쓴다.

## 확정 판정 사례

- 소유자 점유: 대항력 있는 임차인 없음, 임차보증금 인수 0원
- 조사된 임차내역 없음: 충돌 자료가 없으면 대항력 있는 임차인 없음,
  임차보증금 인수 0원
- 후순위 임차인: 전입 효력일이 말소기준권리일과 같거나 늦으면 대항력 없음,
  임차보증금 인수 0원
- 선순위 가능 임차인: 대항력 가능으로 표시하되 배당 결과가 없으면 실제
  인수금액은 확정하지 않음
- 보증기관 잔존채권 포기: 명시적인 잔존 임차보증금반환채권 포기 문구가 있을
  때만 해당 임차보증금 인수 0원. 관련 RAG는 예외 설명과 문구 검토에 사용
- 채권금액·채권최고액·청구금액: 배당 근거 없이 인수금액으로 사용하지 않음

## 예외 안전장치

임차인이 없더라도 유치권, 법정지상권, 분묘기지권, 지분매각, 대지권 미등기,
선순위 가처분·가등기, 임차권등기 신호가 있으면 전체 인수권리를 없음으로
확정하지 않는다. 임차인 부분만 없음으로 고정하고 전체 인수 여부는 RAG와 추가
자료 검토로 넘긴다.

- 네 가지 요청 사례 모두 서버 확정 결과로 교정되는지 확인
- 임차인 없음 + 유치권 사례에서 전체 인수금액을 0원으로 오판하지 않는지 확인
