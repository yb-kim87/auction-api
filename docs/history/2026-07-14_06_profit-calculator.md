# 물건 상세페이지 수익계산기 추가

날짜: 2026-07-14
관련 레포: auction

## 배경

물건 상세페이지에 "입찰가/매도가를 입력하면 최종수익이 얼마인지" 보여주는 수익계산기를
추가해달라는 요청. 사용자가 직접 만들어 쓰던 엑셀 수익률계산시트(경매코치 수익률 계산 시트)의
계산식을 그대로 웹 화면으로 옮기는 방식으로 진행.

## 실행 프롬프트 (요약)

```
물건 상세페이지에 수익계산기를 넣으려고 하는데 내가 기존에 만들어놓은 수익계산 엑셀시트가
있는데 해당 시트내 계산 값들을 보고 수익계산기를 만들어 줄 수 있어?
입찰가(낙찰가) / 매도가를 입력하면 최종수익이 얼마나 되는지에 대한 건데
시트내에 대출계산하는게 있지만 어차피 우리는 대출계산에 대해선 이미 계산식을 만들어뒀으니
그 계산식에 내가 넣은 입찰가/물건 자체 감정가를 적용해서 수치가 기입되게 해주면 될꺼같고
각종 명도비, 미납관리비 같은건 엑셀시트에 적혀있는 값으로 일단 기본 세팅을 해주면 될꺼같아
나머진 수식 참고해서 만들어주면 될꺼같아
수익계산기 버튼 혹은 탭은 레이아웃상 너가 괜찮아 보이게 만들어주면돼
엑셀 파일 경로: E:\OneDrive\auctiondev\수익률계산시트.xlsx (시트: 수익률계산시트)
추가로 양도세율은 (사용자가 보낸) 과세표준 구간별 세율/누진공제표를 참고하여 수식을 넣어줘
(대출계산 연동 방식 확인) 기존 대출계산식 자동 연동
(양도세율 보유기간 반영 여부 확인) 보유기간과 무관하게 항상 구간별 누진세율만 적용
우리는 매매사업자를 활용한 사업자용 세율을 적용할꺼라서 단기매도 해도 저 세율을 적용해도돼
```

## 엑셀 시트 분석

파일이 한글 시트명/셀 인코딩이 깨져 있어(mojibake) openpyxl로 셀 좌표·수식만 추출한 뒀,
사용자가 추가로 보내준 스크린샷("입찰가 산정 및 수익률 분석")으로 각 셀의 실제 라벨을 확인.

핵심 계산 흐름(엑셀 셀 좌표 기준):
- `B4`(입찰가율) = 낙찰가/최저가
- `E7/F7` = 감정가×70%, 낙찰가×80% → `G8`(대출) = `MIN(E7:F7)`
- `G9`(실투자금) = 취득금액합계(B15) − 대출(G8)
- `G10`(수익률%) = 최종수익(B22) / 실투자금(G9)
- `B8`(등기비용) = 낙찰가 × 취득세율(`C8`, 구간별 1~3% + 지방교육세 등 +0.7%)
- `B12`(중개수수료 매도) = 매도가 × 요율(`C12`, 매도가 구간별 0.4~0.7%)
- `B13`(대출이자) = 대출금 × 연이자율(4.5%) / 12 × 보유월수(6)
- `B15`(취득금액합계) = SUM(낙찰가+등기비용+인테리어+명도비+미납관리비+중개수수료+대출이자+중도상환수수료)
- `B18`(매매차익) = 매도가 − 취득금액합계
- `B19`(소득세) = 매매차익 × 양도세율 − 누진공제(엑셀 예시에서는 24% 단일세율만 곱해 실제
  구간별 누진공제표는 비어 있었음 — 이번에 사용자가 준 표로 정식 반영)
- `B22`(최종수익) = 매매차익 − 소득세 − 부동산추가수수료 − 부가세

엑셀 값(최저가 245,000,000 / 감정가 350,000,000 / 낙찰가 255,000,000 / 매도가 300,000,000
/ 보유6개월)으로 대출·등기비·이자·중개수수료·취득금액합계·실투자금·매매차익까지 전부 검증해
동일한 값이 나오는 것을 확인함(대출 204,000,000 / 등기비 4,590,000 / 대출이자 4,590,000 /
중개수수료 1,200,000 / 취득금액합계 268,380,000 / 실투자금 64,380,000 / 매매차익 31,620,000).

## 양도세율(양도소득세) 처리

사용자가 제공한 과세표준 구간별 세율/누진공제표:

| 과세표준 | 세율 | 누진공제액 |
|---|---|---|
| 14,000,000 이하 | 6% | 0 |
| 14,000,000 초과 ~ 50,000,000 이하 | 15% | 1,260,000 |
| 50,000,000 초과 ~ 88,000,000 이하 | 24% | 5,220,000 |
| 88,000,000 초과 ~ 150,000,000 이하 | 35% | 14,900,000 |
| 150,000,000 초과 ~ 300,000,000 이하 | 38% | 19,400,000 |
| 300,000,000 초과 ~ 500,000,000 이하 | 40% | 25,400,000 |
| 500,000,000 초과 ~ 1,000,000,000 이하 | 42% | 35,400,000 |
| 1,000,000,000 초과 | 45% | 65,400,000 |

**보유기간과 무관하게 항상 이 구간별 누진세율표만 적용한다.** 매매사업자를 활용한
사업자용 세율 구조라 개인 단기양도(1년 미만 70% 등) 세율 체계는 도입하지 않음.

## 변경 내용 (auction)

- `src/lib/profit-calculator.ts` 신규
  - `acquisitionTaxRate(minPriceWon)`: 취득세율(구간별 1~3% + 1.1배 + 0.7%p)
  - `saleBrokerageRate(salePriceWon)`: 매도 중개수수료율(구간별 0.4~0.7%)
  - `capitalGainsTaxBracket(taxBaseWon)`: 양도세 구간별 세율/누진공제(위 표)
  - `calculateProfit(input)`: 대출한도부터 최종수익·수익률까지 전체 계산
  - `isOver85Sqm(area)`: 물건의 `area` 문자열에서 전용면적을 파싱해 85㎡ 초과 여부 판정
- `src/components/ProfitCalculatorPanel.tsx` 신규
  - 낙찰가(입찰가) 초기값 = 물건 `minPrice`, 매도가 초기값 = 물건 `appraisedValue`
  - 대출비율(감정가/낙찰가 기준)은 `AuctionDetailModal`이 이미 갖고 있는
    `loanRatio`/`appraisalRatio`(기존 대출정책 계산 결과)로 기본 세팅, 관리자가 필요 시 직접 수정 가능
  - 인테리어(200만원)/명도비(200만원)/미납관리비(100만원)/중도상환수수료(0%)를 기본값으로 세팅
    (2026-07-15 사용자 제공 참고 이미지 기준으로 조정, 아래 追記 참고)
  - 등기비용, 매도 중개수수료는 자동계산 값이라 읽기 전용으로 표시(직접 수정 불가)
  - 85㎡ 초과 물건일 때만 부가세 입력란 노출
- `src/components/AuctionDetailModal.tsx`: "기본정보" / "AI에게 물어보기" 옆에 "수익계산기" 탭
  추가(회원 상세보기 모드에서만 노출, 편집 모드에서는 숨김)

## 결과
- 상세페이지에서 낙찰가·매도가·보유기간 등을 바꾸면 실시간으로 대출금·실투자금·수익률·최종수익이
  재계산됨
- 대출한도 계산은 기존 대출정책 로직과 동일한 값으로 시작하되, 필요시 시나리오별로 직접
  비율을 조정해볼 수 있음
