# 물건 카드 썸네일 이미지 교체

날짜: 2026-07-14
관련 레포: auction

## 배경

추천 물건 카드의 아파트/빌라 썸네일 이미지가 실제 물건 유형과 어울리지 않는 사진
(예: 사람이 공구 작업하는 사진)으로 표시되던 문제.

## 실행 프롬프트 (요약, 시간순)

```
1이미지는 빌라 2이미지는 아파트인데 상단에 들어가는 이미지에 빌라와 아파트 이미지에
어울리는 이미지로 넣어줄 수 있어? 실사같은 이미지로
내가 이미지를 보내줄께 위에가 빌라고 아래부분이 아파트야 이걸로 써줘
E:\OneDrive\auctiondev\ChatGPT Image ....png (직접 제공한 이미지 파일 경로)
```

## 변경 내용

1. **1차: Unsplash 무료 이미지로 교체** — 아파트/빌라 외관이 실제로 잘 드러나는 Unsplash
   사진 URL로 교체(외부 URL 방식 유지).
2. **2차: 사용자 제공 이미지로 최종 교체** — 사용자가 위(빌라)/아래(아파트)가 합쳐진 이미지
   파일을 직접 제공. Python(Pillow)으로 상하 분할해 `public/thumb-villa.jpg`,
   `public/thumb-apartment.jpg`로 저장 후 로컬 경로(`/thumb-villa.jpg`, `/thumb-apartment.jpg`)로
   교체.

### 적용 위치
- `src/app/page.tsx`: 추천 카드/리스트뷰 썸네일
- `src/components/AuctionDetailModal.tsx`: 상세페이지 상단 이미지

## 결과
- 외부 URL 의존 없이 프로젝트 자체 정적 자산으로 아파트/빌라 물건 유형에 맞는 실사 이미지 표시
